1. Executive Overview

Wave 31 transitions HEX-AIM from static mock exam sitting to an autonomous, cognitive decay-aware examination synthesis platform. Traditional mock testing induces acute working memory fatigue in neurodivergent learners when overwhelmed by early multi-step questions.

The newly shipped GenerativeMockEngine dynamically synthesizes calibrated exam papers utilizing:

  • Ebbinghaus Retention Weighting: Projects realistic readiness percentages and confidence intervals calibrated against student review intervals $R(t) = R_0 \cdot 2^{-t / S}$.
  • Graduated Anxiety Progression: Structure follows Bloom's Taxonomy: Warmup Recall (Bloom 1–2) → Targeted Gaps (Bloom 3) → Synthesis (Bloom 4).
  • Isomorphic Parameterization: Dynamically replaces values and names with cognitive misconception distractors to prevent rote memorization.
  • Instant Sitting Registration: Automatically registers generated papers directly into ExamSimulationEngine, allowing seamless one-click launches at /exam/<examId>?student=<id>.
