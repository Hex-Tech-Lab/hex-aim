Key words

Jump
the same amount added each time
Rule
the jump: "add ___" or "take away ___"
Sequence
numbers that follow one rule
Gap
the space between two next-door numbers

Example 1: going down (rule: subtract 6)

Question: 78, 72, 66, ___, ___

78−6→72−6→66−6→60−6→54

Each number is 6 less than the one before. From the lesson slide: 60, 54.

Example 2: going up (rule: add 25)

Question: 14, 39, 64, 89, ___, ___

14+25→39+25→64+25→89+25→114

Big jumps still work the same way. 89 + 25 = 114, then 114 + 25 = 139.

Example 3: a number is missing (count in 3s)

Question: 0, 3, 9, 12, 15, 21. Which one is missing?

0+3→3+3→6+3→9+3→12+3→15+3→18+3→21

Every jump is 3. The gap from 3 to 9 is 6 = two jumps of 3, so 6 is missing.

Example 4: count back past zero (steps of 4)

Question: start at 0, count back 4s. Give two numbers.

0−4→−4−4→−8

Below zero the numbers are negative. Each step is still 4, so: −4, −8.

Before you answer, check (3 steps)

  1. Find the jump: take one number away from the next.
  2. Test that jump on a pair you already know.
  3. Use the same jump to fill the blank.

Find the jump. Add it. Done.
