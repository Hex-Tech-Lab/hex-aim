# Parent-facing acronym code: learning differences and conditions

**Why this exists:** parents may read AIM messages in front of their children. Full condition names can label a child in public. In parent-facing text, every condition is written as a two-letter code, using the house pattern: a capital letter, then a small letter. The full name is never shown on a child-facing page.

**Rule:** use the code in parent-facing and child-facing output. Use the full name only in clinical records the parent has consented to, and never on a page a child can see.

| Code | Full name (internal only) | Typical age range | Notes |
|---|---|---|---|
| **Ad** | ADHD: attention-deficit/hyperactivity disorder | 5–12 | Attention, working memory, time pressure. Lara's profile notes speed-pressure vulnerability. |
| **Dx** | Dyslexia: specific reading difficulty | 5–12 | Decoding and reading speed. |
| **Dc** | Dyscalculia: specific number-processing difficulty | 6–12 | Place value, number sense, sequences. |
| **Dg** | Dysgraphia: specific writing difficulty | 5–12 | Handwriting, spacing, letter order. |
| **Dp** | Dyspraxia / DCD: developmental coordination disorder | 5–12 | Motor planning, coordination, handwriting. |
| **Au** | Autism spectrum condition | 2–12 (all ages) | Routines, sensory load, social communication. |
| **Dl** | Developmental language disorder | 3–12 | Spoken and written language. |
| **An** | Anxiety disorder | 5–12 | Test anxiety, avoidance, freezing. |
| **Td** | Tic disorder or Tourette syndrome | 5–12 | Tics that come and go; may show under stress. |

## How to write it

- Correct: "Ad support: break the quiz into short timed blocks." Incorrect: "ADHD support: …"
- Put the code on first use, then the code alone after. Do not spell out the full name anywhere on a child-facing page.
- A child's profile may carry several codes, for example "Ad, Dx". List them in alphabetical order.
- A child with no documented condition gets no code. Do not infer one.

## Conditions not coded here

If a condition is not in this table, do not invent a code. Write "a learning profile on file" and send the family to the school SENCO.

## Maintenance

- Adding a code means a new row, a new code that starts with a capital letter, and a note here.
- Codes are only for parent-facing and child-facing text. Internal code and the database keep full names.
