2. Technical Core Moats

🛡️ Cryptographic Integrity Chaining

Uses recursive canonical key serialization (canonicalStringify) guaranteeing identical SHA-256 digest computation across platforms. Any grade inflation or modified OCR transcript immediately triggers a verification failure.

☁️ Tiered Cloudflare R2 Offloading

Heavy page scans and raw payloads are packaged into cold storage manifests under aim-student-dossiers with 1-hour time-limited presigned URLs (HMAC-SHA256), preventing public scraping while maintaining instant parental access.
